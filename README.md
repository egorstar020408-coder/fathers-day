# 🎸 Интерактивная открытка ко Дню отца

Живая музыкальная веб-открытка для самого лучшего папы на свете!

👉 **[Открыть открытку онлайн](https://egorstar020408-coder.github.io/fathers-day/)**

## ✨ Особенности:
- 🎸 **Вылет гитары на сцену**: динамичное появление инструмента в лучах прожекторов.
- 🎶 **Звук струн (Дрынь!)**: синтез звука реальной акустической гитары по алгоритму Karplus-Strong через Web Audio API.
- 💥 **Взрыв нот и трансформация**: сотни светящихся нот вылетают из резонатора и выстраиваются в слова «С ДНЁМ ОТЦА! ❤️».
- 🎵 **Интерактивные струны**: можно проводить пальцем или кликать по струнам, играя ноты.
- ⚡ **Рок-соло**: кнопка воспроизведения рок-риффа с визуальным боем струн.
- 💬 **Пожелания**: генератор тёплых слов и поздравлений.
- 📱 Полная адаптивность под смартфоны и ПК.
